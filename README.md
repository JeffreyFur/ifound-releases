Depots publics des livrables clients. Le code source reste prive dans un autre depot.

### Windows (recommande)

Telecharger `iFound_Mining_Windows_Portable.zip`, le decompresser entierement, puis lancer `iFound_Mining.exe` depuis le dossier decompresse.
Le fichier `.exe` seul ne fonctionne pas (il lui manque les DLL et `data\app.so`).

### Android

Installer `iFound_Mining.apk` (source inconnue autorisee).
